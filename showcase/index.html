Using it

Drop-in, no build step required

<script type="module" src="/language-picker/language-picker.mjs"></script>
<language-picker
  langs="sk,en,de"
  current="en"
  mode="path-prefix"
></language-picker>

Ships a minimal bundle

The subsetting CLI builds only what a given langs list needs — data, flags, and modules — mirroring this exact usage.

node scripts/subset.mjs \
  --langs sk,en,de \
  --out ./dist/language-picker
